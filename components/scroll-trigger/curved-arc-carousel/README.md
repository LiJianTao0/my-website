# 个人内容输入模板

这是你的**个人网站内容输入模板**。按照下面的结构，把内容填进去，就能生成你的个人主页。

## 一、个人介绍

填写你的基本信息，让访客认识你。

| 内容项 | 填写位置 |
|--------|---------|
| 姓名 | 封面书名、左页品牌名 |
| 一句话简介 | 封面副标题 |
| 详细自我介绍 | 左页"你好"段落 |

## 二、我的作品

在作品网格里展示你的项目，每个作品一张卡片。

| 内容项 | 填写位置 |
|--------|---------|
| 作品名称 | 卡片标题 |
| 作品简介 | 卡片描述（一句话） |
| 作品演示/下载 | 卡片的"打开/下载"入口 |

## 三、联系方式

让访客能找到你。

| 内容项 | 填写位置 |
|--------|---------|
| 邮箱 | 联系按钮指向的链接 |
| 社交账号 | 联系区链接 |
| 头像 | 左页头像图片 |

## 怎么填

- **文字内容**：编辑 `src/curved-arc-carousel.html`，把卡片里的占位文字替换成你的内容（每张卡 = 编号 + 小标签 + 描述）
- **图片素材**：放进对应目录，替换引用路径
- **保存即刷新**：Vite 热更新，改完立刻看到效果

## 模板已就绪

动画、布局、样式都已配好，你只需要**替换文字和素材**，不需要写代码。
